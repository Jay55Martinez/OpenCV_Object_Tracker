## Description:

This OpenCV-based project centers around the development of a 2D-tracking robot equipped with a camera for real-time object detection and recognition. The goal is to design a mobile system capable of identifying, tracking, and following target objects across a two-dimensional plane using computer vision techniques.

As part of this project, I aim to deepen my understanding of the OpenCV library while gaining hands-on experience with integrating software and hardware components in a robotics context. The robot will initially support basic 2D movement and object tracking, with plans to enhance its mobility and precision in future iterations.

In addition to software development, I am collaborating with a mechanical engineer to design a custom chassis and housing for the robot. All mechanical components are being designed using CAD software, and the final models will be shared in this repository alongside the source code and other supporting resources.

This project not only serves as a personal learning experience but is also intended to be an open and replicable design process for others interested in robotics and computer vision.
